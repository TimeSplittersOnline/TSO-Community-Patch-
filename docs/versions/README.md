# Every version

Each page compares a delivered build with the one before it. Every change to the game's own code and data is listed in full, with what was there before, what it became and its purpose (as in the current build; a change later removed shows none). Changes to the mod's added code, in memory the game never uses, are summarised; their full bytes are in that version's release files. Versions before v5.3 were not kept as files; they are in the [changelog](../../CHANGELOG.md).
